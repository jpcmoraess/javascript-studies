# JavaScript Studies

Exercícios de fundamentos de JavaScript executados com Node.js, feitos durante meus estudos de lógica de programação.

## Conteúdo

| Arquivo | O que pratica |
|---|---|
| `nodejs-estudos/operadoresMatematicos.js` | Operadores aritméticos e template strings |
| `nodejs-estudos/lacofor.js` | `for` clássico e `for...of` percorrendo strings |
| `nodejs-estudos/lacowhiledowhile.js` | `while` e `do...while` |
| `nodejs-estudos/desafioLacoRepeticao.js` | Contagem de números pares e ímpares de 0 a 100 |
| `nodejs-estudos/listaExerciciosLacos.js` | Lista de exercícios: conversão Celsius para Fahrenheit, fatorial com validação de entrada, sequência de Fibonacci, soma dos dígitos, pirâmide de asteriscos e contagem de notas e moedas |

## Como executar

Requer [Node.js](https://nodejs.org/) instalado.

```bash
git clone https://github.com/jpcmoraess/javascript-studies.git
cd javascript-studies/nodejs-estudos
node listaExerciciosLacos.js
```

## Tecnologias

JavaScript (ES6+) e Node.js.
